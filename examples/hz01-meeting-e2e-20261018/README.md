# hz01 会议应用端到端工作流

这两个 JSON 是 2026-10-18 从 hz01 正在使用的 Audio Harness 控制面导出的 active 工作流，保存原字段及版本信息，便于核对部署。

- `ai-meeting.json`：会议应用的普通语音入口。
- `ai-meeting-diarize.json`：应用默认说话人选项的兼容别名。

两者使用真实 VAD 与 ASR，按单说话人占位；没有部署真实说话人分离。多麦仲裁由测试采集器调用独立的真实 gRPC 仲裁服务，然后按原 Collector ATP 协议接入媒体网关。SID 不是本轮必需依赖。

模型地址属于 hz01 的部署配置，迁移到其他机器时通过已有控制面调整。这里导出工作流配置，不包含会议音频、转写、账号口令或模型密钥。

同步分支同时保留本地近期的 UI 与占位聚类修改，并合入 hz01 的已提交验证记录；没有新增或修改语音通讯协议。
