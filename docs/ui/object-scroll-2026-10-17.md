# 工作流与智能体的对象级滚动

以推理引擎的固定视口布局为参照。桌面视口内，应用导航不参与业务内容滚动；每个滚动条只属于正在操作的对象。沿用现有苍渊、白垣语义变量，不新增颜色，不调整移动端。

## 页面与滚动归属

| 页面 | 固定区域 | 独立滚动区域 |
| --- | --- | --- |
| 工作流、智能体列表 | 应用导航、页面标题、新建操作、列表标题、刷新、表头 | 对象记录 |
| 智能体创建 | 应用导航、页面标题、表单标题、取消与创建动作 | 表单字段 |
| 工作流、智能体构建 | 对象信息、目录标题与搜索、画布工具栏、保存状态、属性标题与页签 | 节点目录、画布、属性正文分别处理 |
| 工作流、智能体接入与测试 | 应用导航、侧栏对象信息、阶段导航、保存动作 | 当前对象的接入或测试内容 |
| 工作流、智能体历史 | 应用导航、对象信息、阶段导航、历史标题 | 发布记录 |

工作流创建继续保留填写与主题切换的既有行为。创建期间优先展示当前表单，取消后恢复列表，避免表单挤掉列表滚动区。极矮桌面窗口先减少留白，长对象信息允许在自身区域内滚动，节点目录必须保留可操作高度，保存动作始终可达。

滚动到对象内容的边界后，不应继续带动整页滚动。记录和节点目录支持键盘聚焦及原生滚动；列表表头与记录为独立容器时应保留相同滚动条占位，保证列对齐。

## 前端同步与验证

滚动边界集中在 `src/web/src/styles/objectScrolling.css.ts`，桌面规则沿用现有 `1101px` 分界。列表与历史分别增加可聚焦的记录容器；智能体侧栏拆分对象信息和节点目录；工作流非构建阶段移除 `620px` 最小高度对视口的撑开限制。画布继续使用原有缩放和平移，属性编辑和保存逻辑保持原调用链。

- TypeScript、ESLint、Vite 构建通过；现有 17 个测试文件、189 项前端测试通过。
- 模拟 API 数据：100 条工作流、100 条智能体、两个模块各 80 条发布记录。没有调用真实发布、恢复或推理服务。
- 11 页 × 2 主题 × 4 组桌面尺寸，共 88 次布局检查：`1440×1000`、`1440×600`、`1440×400`、`1280×600`。均无整页横向或纵向溢出，所检查局部内容区均有可用高度，操作按钮未超出视口。
- 实际滚轮检查：对象内容能滚动，滚动到边界时页面位置为零，应用导航位置不变。
- 6 个列表、历史和节点目录场景用键盘聚焦末项，滚动留在所属容器内；两个对象列表的表头与行列起点误差小于 1px。
- 另测工作流创建在 `600px`、`400px` 高窗口中的表单滚动、主题切换保留输入、取消后恢复列表，以及智能体空状态的局部滚动。

截图与原始核验结果保存在 `tmp-workspace/ui/2026-10-17/object-scroll/`：`report.json`、`keyboard.json`、`figma-audit.json`。这些浏览器检查使用模拟 API，覆盖布局和滚动行为；真实音频会话未在本次重启或执行。
