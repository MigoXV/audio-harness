## 补齐的主要结构

推理引擎不再把完整详情挤在旧抽屉里。列表与服务详情分开呈现，模型、音色、引用拥有明确视图。检查结果同时标注时间和历史属性；服务已停用、请求失败、目录失败与引用阻断仍由真实状态决定。注册使用 480px 抽屉，编辑使用 560px 居中弹窗；连接配置在前，标识在后，描述和超时归入高级参数，标题与动作固定、正文滚动。取消编辑曾出现详情重复渲染，已修正兄弟组件的重复 React key，并添加回归验证；返回列表和关闭编辑各自恢复适当焦点。

智能体采用 232px 紧凑节点、单行摘要、对应线性图标和成对端口行。左侧增加六个真实拓扑节点的定位入口；右侧为 280px 固定属性栏，含“基础配置 / 输入与输出”。属性正文独立滚动，模型、提示词和模板使用更轻量的行式配置。输入输出、上游与下游均由当前拓扑计算；输入、输出边界也可审阅。切换页签不丢失草稿，Escape 关闭后焦点返回选中节点。

向量检索的创建入口移到 Collection 目录内。向量配置改为真正的表格，分别表达启用、名称与维度、推理服务、模型和归一化；登记信息为两列对齐字段，JSON 与提交操作留在同一任务区。上传、录音、VAD 裁剪、人物搜索、登记与记录继续使用已有 API，不把设计样例勾选状态覆盖到实际表单。

## 约束与明确差异

- 继续只使用既有苍渊·白垣语义 Token。新稿中预设外的类型色不直接写入代码；节点、端口、连线与图例复用同一套允许的颜色映射。原生选框也显式绑定主题色，避免浏览器默认蓝色混入白垣。
- 工作流原有独立测试页保留。草稿中的底部测试控制台、画布优先实验没有直接替换正式页面；草稿注释明确部分迭代只调整右侧属性，正式画布和工具栏保持原样。
- ASR 语言与输出模式没有对应可保存的现有节点字段，未添加不能生效的控件。
- 音色管理接口仅提供目录，没有按引擎试听的方法。界面明确禁用“试听”，复制 ID 可正常执行；没有把静态按钮当成已实现的音频能力。
- 引擎沿用“保存并复检”的真实先后顺序，不将它误写成具有原子保证的“验证并保存”。API Key 仅在支持该字段的接口类型中出现，并使用密码输入；Slug 继续遵循现有必填及自动生成规则。
- Figma 的固定示例拓扑、背景分区与连线路径不覆盖用户保存的图；保留真实测量、拖动、自动排列和适配视野。
